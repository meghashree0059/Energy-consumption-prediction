# Energy-consumption-prediction
ML-based energy consumption prediction system using Python &amp; Scikit-learn to forecast hourly power usage from historical energy data. Performed data preprocessing, datetime feature engineering, model training,&amp; evaluation using regression algorithms Random Forest Regressor. Visualized actual vs predicted energy consumption trends using Matplotlib 

**Technologies Used:**
1. Python
2. Pandas
3. NumPy
4. Scikit-learn
5. Matplotlib
6. Jupyter Notebook

**Features:**
1. Data preprocessing and cleaning
2. Time-based feature engineering
3. Energy consumption forecasting
4. Regression model training and evaluation
5. Visualization of prediction results

**Model Used:**
Random Forest Regressor

**Outcome:**
Successfully predicted hourly energy consumption patterns with good accuracy using machine learning techniques and time-series based features.
